## 4. Chạy thật: API → OTel Collector → Tempo (T018-6)

Dựng tạm `grafana/tempo:2.6.1` + `otel/opentelemetry-collector-contrib:0.115.1` bằng đúng tệp cấu hình của repo (`TRACE_SAMPLE_PERCENT=100`), API nhánh W5 trên `ketoan_test`, `OTEL_EXPORTER_OTLP_ENDPOINT=http://127.0.0.1:14318`. Kịch bản: lập → duyệt → chi yêu cầu thanh toán (gửi `traceparent`), rồi chi lại lần hai. Hỏi Tempo `GET /api/traces/<traceId>` sau 20 giây.

| Trace | Kết quả trên Tempo |
|---|---|
| Chi tiền (thành công) | **34 span**: `HTTP POST …/:id/pay` (`outcome=ok`) → `action quy.payment-request.pay` (`module=quy`, `idempotency=new`) → `kernel voucherService.createIn` (`layer=K`, `doc_type=payment`) → 30 span `db …` → `event publish bizcity.ledger.entry.posted` |
| Chi lại (từ chối) | 6 span; HTTP + action `outcome=rejected`, `error.code=CONFLICT`, 409; **không** có span `kernel` (bị chặn trước khi vào sổ — đúng). `error.traceId` trong phản hồi mở đúng trace này |
| Dò lộ dữ liệu trong JSON trace của Tempo | không có số tiền `7654321`, mã `NCC-E2E`, tên "Bí Mật", `$1`, `Bearer`, token phiên |
| TraceQL `{ span.bizcity.module = "quy" }` | trả trace của module `quy` |

Điều tra mẫu (khớp ADR-0010 §6): từ phản hồi lỗi lấy `error.traceId` → Tempo → thấy lỗi nằm ở action của module `quy`, Kernel không được gọi, sổ không đổi; bằng chứng tra theo `audit_logs.trace_id`. Không cần đọc mã module, không đụng Kernel.

## 5. Chi phí trên đường ghi sổ (mốc R-KER-9)

`POST /api/v1/documents` (bán hàng, định khoản ngay), tuần tự, 30 lượt khởi động + 300 lượt đo, 2 lượt mỗi chế độ; máy dev Windows, API `tsx`, PostgreSQL trong Docker Desktop. Kịch bản: `bench-ghi-so.mjs` (scratchpad của phiên).

| Chế độ | p50 (ms) | p95 (ms) | trung bình (ms) |
|---|---|---|---|
| Tắt SDK (`OTEL_SDK_DISABLED=true`) — mốc | 66,0 · 65,7 | 73,1 · 80,0 | 66,5 · 66,8 |
| SDK bật, không xuất | 68,5 · 65,8 | 78,6 · 76,8 | 69,0 · 66,7 |
| SDK bật, xuất qua Collector | 65,7 · 69,3 | 74,9 · 83,4 | 66,2 · 70,4 |

So mốc (trung bình hai lượt): xuất trace **+2,5%** trung bình, **+3,4%** p95 → **đạt** ngân sách ≤ 5%. Không xuất: +1,8% trung bình, +1,5% p95 — **chưa chứng minh được** ngân sách ≤ 1%: hai lượt cùng chế độ đã lệch tới ±5% trên máy này, sai số lớn hơn ngưỡng. Đo lại trên máy chủ thật cùng mốc S018-4.
